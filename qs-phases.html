1.　假設工程

工種工序
鷹架工程定期檢查 → 拆除 → 施工圖面檢討 → 進料/吊料 → 組裝
放樣工程基準點設置 → 地界線放樣 → 擋土設施放樣 → 地下室開挖測量 → 結構體放樣 → 室內隔間放樣
施工電梯工程定期保養檢查 → 施工前研討 → 材料進場/組裝 → 結構體檢核 → 拆除 → 現場使用 → 試車/移交 → 爬昇
施工塔吊工程擬定施工計劃 → 基礎施工或結構補強 → 按裝 → 定期保養檢查 → 預留孔 → 爬昇 → 拆除 → 試車/移交 → 塔吊使用

4.　泥作工程

工種工序

泥作粉刷工程施工前清潔濕潤 → 放樣灰誌 → 鋪面 → 打底 → 粉光 → 出線盒處理 → 塞水路/滴水線 → 完工清潔
貼壁磚工程磁磚計劃訂定 → 舖貼面整修/打底 → 貼面放樣 → 貼磁磚 → 填縫勾縫 → 磁磚清洗
貼地磚工程磁磚計劃訂定 → 舖貼面整修/打底 → 貼面放樣 → 貼磁磚 → 填縫勾縫 → 磁磚清洗 → 防地磚隆起（條件式）
地坪粉刷工程清潔濕潤 → 純水泥漿塗佈+水泥砂漿鋪面 → 洩水坡度施工 → 加鋪鐵絲網/基準灰誌（條件式） → 粉光面驗收
輕質磚工程施工前準備及檢查 → 第一層磚施工 → 第二層以上磚施工 → 與 RC 牆接合 → 與木門框配合 → 與水電配管配合 → 防水工程施工 → 批土工程施工 → 與廚具/衛浴接合
