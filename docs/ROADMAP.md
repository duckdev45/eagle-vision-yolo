## ② 缺失檢查軸

**先分類再選工具**——1,075 個 REQUIRED 項不是同一種問題（`uv run src/qsdata.py` 實測）：

| 類型 | 佔比 | 判定方式 |

| B 量測數值 | 19.3% | VLM 判「照片裡有沒有尺」（標準常明文要求，如 QS0701-4.14） |
| C 文件憑證 | 12.5% | OCR，不同技術棧 |
| D 時序流程 | 4.1% | 日報時間戳比對，純規則 |
| E 儀器試驗 | 2.2% | 試驗報告擷取，走 C 的路 |

A+B = **81.2%** 落在 vision 守備範圍 → vision 是主軸，可放心投資。
C+D+E 集中在材料檢驗與定期檢查，可整批延後。

- 最高槓桿：**退回按鈕寫入 QS 代碼**——現在不加，一年後就是 0 筆缺失標籤（時間不可逆）
- 請款照片靶 8 項（明文須拍照存證）＋罰則 6 項已可查（`make qs`）→ 小資料集二元判定 PoC 是首選落地
